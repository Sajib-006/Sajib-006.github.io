## Site maintenance

The site is built with Jekyll and deployed from `master` by the GitHub Actions workflow in `.github/workflows/pages.yml`.

To preview it locally after installing the bundle:

```bash
bundle install
bundle exec jekyll serve
```

The visual foundation is derived from the open-source [AcademicPages](https://github.com/academicpages/academicpages.github.io) theme. See [LICENSE](LICENSE) for licensing information.
